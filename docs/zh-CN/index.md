欢迎阅读 Mosona Manager 文档。如有任何问题或需要进一步帮助，欢迎联系支持团队或加入社区讨论。

## 什么是 Mosona Manager？

Mosona Manager 是一款面向团队 / 个人的项目管理、服务器监控与终端管理工具，具备完善的项目权限控制，以及基于 Agent 与 SSH 的远程管理能力。
