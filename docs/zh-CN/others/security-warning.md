# 安全警告

> 如需报告漏洞，请访问 [GitHub Security](https://github.com/mosona-labs/mosona-manager/security)，按说明提交 issue 或私下报告。我们会尽快响应并处理。

本页旨在说明不安全使用本项目可能带来的风险。请始终遵循安全最佳实践，保护你的系统与数据。

## 为什么这件事很重要

本项目包含远程控制与执行能力（在启用远程控制时）。在 SSH 模式下，它会将连接信息——例如主机地址、用户名、密码与密钥——存储在数据库中。尽管这些数据已加密，但若攻击者获得更高权限（例如从数据库提取数据，或逃逸出容器），仍可能取回加密密钥并解密信息。

任何入侵或攻击都可能造成严重后果。远程探测类能力本身就带有这类安全风险，没有任何项目能完全消除——即便本地 SSH 客户端也可能被恶意软件窃取凭据。因此，遵循安全最佳实践至关重要。

历史上无数项目都因安全疏忽付出过惨痛代价。便捷与速度往往以额外风险为代价，我们会尽可能降低暴露面。

## 安全最佳实践

### 1. 避免弱密码

设置符合控制面板密码强度要求的强密码。

### 2. 启用双因素认证（2FA）

请始终启用基于 TOTP 的双因素认证，或邮箱验证。即便密码泄露，攻击者也难以轻易登录。

### 3. 强制访问隔离

初始设置时必须绑定基础 URL（Base URL）。之后控制面板仅能通过该 URL 访问。建议绑定到专用域名，而不是使用 IP 地址。

对于公开页（Public Pages），最佳实践是使用单独的专用域名，而不是通过主控制面板路径共享访问。本项目会阻止来自公开页域名的所有管理 API 访问。

### 4. 使用 Cloudflare Tunnel 或 VPN

若需要从公网访问控制面板，请使用 Cloudflare Tunnel 或 VPN，避免直接暴露服务器。攻击者一旦发现实例关联 IP，可能尝试直接攻击；隐藏 IP 能显著降低这一风险。

### 5. 用 Cloudflare Access 或 Zero Trust 保护控制面板

Cloudflare Access 或 Zero Trust 可提供额外的强认证与访问控制，确保只有授权用户或组织内部用户能访问控制面板。这是最有效的安全措施之一。

### 6. 保持自动更新开启

不要关闭自动更新。运行最新版本可确保始终获得最新的安全修复与改进。
