# 版本记录

## v0.1.16 (04/09/2026)

Github: [3ef7752...5b9fcc1](https://github.com/mosona-labs/mosona-manager/compare/3ef7752d57e1a30d33343784ebaa2d74deff18d2...5b9fcc1f7f5df04be20a26205d36aef5e84138a1)

#### 修复

1. 修复服务器告警通知从不触发的问题：批量 InfluxDB 告警查询将单一时长分组包裹在 `union(tables: [branch0])` 中，被 Flux 拒绝（`union must have at least two streams as input`），因此当团队对某一项的规则共用同一回看时长（默认配置）时，每个告警评估周期都会跳过所有规则。单一分组查询现在直接输出分支管道。
1. 在 SSH 状态采集时 `df` 部分失败（例如失效的 FUSE 挂载使 `df` 列出所有文件系统后以非零退出）的情况下保留有效磁盘行：磁盘采样现在使用成功解析的行，而不是丢弃整个快照，仅在 `df` 超时或完全没有有效行时才回退到上次缓存的采样。

#### Web

1. 一些细微的设计调整。

## v0.1.15 (30/08/2026)

Github: [3983bdf...3ef7752](https://github.com/mosona-labs/mosona-manager/compare/3983bdf8eea34558239752c4d6c81b472a4671f6...3ef7752d57e1a30d33343784ebaa2d74deff18d2)

> 本版本为主动式 Agent 终端握手增加认证（协议 v2：回复使用 Agent 的 Ed25519 身份密钥签名并由 Hub 固定，中间人无法再冒充 Agent 终端），并加固被动式终端会话（绑定其服务器、原子认领、会话 ID 移出 URL）。无降级路径——应用于自动更新或无人值守实例前请先阅读升级说明，并请在 v0.1.17 之前升级主动式与被动式 Agent（旧握手届时将被移除）。

#### 安全

1. 使用绑定到服务器记录的带版本 AES-GCM 封装，对主动式 Agent 长期私钥进行静态加密；运行时连接与导出拒绝明文或从其他服务器复制的密文。
1. 对非空 Agent UID 强制唯一性，确保已认证的被动式 Agent 身份唯一解析到一个服务器；升级遇重复时失败关闭，团队导入预检冲突时返回针对具体服务器的 409，而非模糊的数据库错误。
1. 团队导出遇到无法读取的凭据时指明受影响的服务器或共享 SSH 密钥：默认跳过无法读取的服务器及依赖被跳过密钥的服务器，并记录在响应与加密包中；`skip_unreadable_servers: false` 请求严格的全有或全无导出。
1. 将被动式终端会话绑定到目标服务器、首次认领时原子消费、使用随机 UUID v4 标识符、要求已安装且启用终端的 Agent，防止跨团队或重复认领；新端点将会话标识符移出 URL，降低反向代理与 WAF 日志暴露。
1. 对主动式 Agent 握手回复的完整转录进行签名与校验，以原子 compare-and-set 固定身份密钥，将会话密钥绑定到转录，以双向验证的 finished 消息确认，应用 15 秒超时，任何校验错误均失败关闭，并在固定到 v2 后拒绝降级到旧握手。
1. 团队导入时校验 Agent `public_key`（PEM 格式与 Ed25519 密钥长度），存储前规范化并重新编码。

#### 新功能

1. 可选的每服务器 `public_visible` 标志（默认可见），仅将服务器从公开状态页隐藏——团队仪表盘、监控与终端不受影响。可在添加 / 编辑时设置；团队导出 / 导入包含该字段，不含该字段的旧包导入时视为可见。
1. 团队导出 / 导入包中的 `protocol_version` 字段，与旧归档向后兼容：升级窗口内未固定的主动式 Agent 保留明确的旧版本，已固定的身份以 v2 导入。
1. 新增 `docs/testing.md`，说明运行测试套件所需的环境变量。

#### 修复

1. 被动式 Agent 注册或主动式服务器创建时使用随机 UUID v4 身份，生成失败时失败关闭，避免可预测或全零的 Agent 身份。
1. 认证连接上的状态快照或编码失败时，Agent 进程不再通过 `log.Fatalln` 退出，而是关闭连接；帧解密失败时重连监控，而不是让流静默失步。
1. 从连接池移除已完成的 worker，避免已停止或不匹配的服务器留下过期条目；Agent 记录缺失时停止重试循环而不是每分钟记录一次错误（含 SSH 服务器），重新运行安装器时复用现有 Agent 身份。

## v0.1.14 (22/08/2026)

Github: [fc4e444...3983bdf](https://github.com/mosona-labs/mosona-manager/compare/fc4e44489da080103679c70040c61429975a21c3...3983bdf8eea34558239752c4d6c81b472a4671f6)

> 本版本降低了较大规模集群下实时监控与告警对 Hub 的负载，并将日志 API 改为基于游标的时间范围查询。`GET /api/v1/logs` 与 `GET /api/admin/logs` 不再支持偏移分页（`page` > 1 返回 400，响应返回 `next_cursor` / `has_more` 而非 `total`），日志查询默认最近 30 天（消息搜索限制在 30 天窗口内；最大跨度 365 天）。

#### 新功能

1. 团队与管理员日志列表端点支持可选的 RFC3339 `start` / `end` 过滤，并采用基于游标的分页（`cursor`、`next_cursor`、`has_more`）。

#### 性能

1. 每个团队的所有 SSE 订阅者共享同一份监控快照（3 秒刷新、8 秒查询超时、64 个并发 Influx 加载），而不是每个打开的仪表盘各查询一次 InfluxDB。
1. 将服务器状态写入 InfluxDB 的操作排队并批量执行（1 万点队列、500 点批次、1 秒刷新），失败批次重试一次，溢出时丢弃最旧的点，并在关闭时与审计日志一起排空队列。
1. 批量执行告警观测查询（每次 64 台服务器，按指标与 `for_duration` 分组）并预聚合窗口，替代每服务器 / 每规则一次 Influx 查询。
1. 并行化管理员仪表盘的 Influx 查询（记录数与系统使用率），带 15 秒上下文超时。

#### 修复

1. 在 `SafeJoinUnderRoot` 中拒绝父路径段（`..`），包括反斜杠分隔的路径，静态文件拼接无法再通过此前会被清理回根目录内的穿越段逃逸。
1. 校验管理员列表分页（`page` / `size`）的共享边界（默认 1/20，最大 100000/1000），无效值返回 400 而不是强制转换。
1. 在管理员用户 / 团队搜索中转义 `LIKE` 通配符，数字 ID 精确匹配，列出团队不再要求成员联接，空团队也会出现在管理员列表中。

#### Web

1. 仪表盘服务器卡片虚拟化并节流 SSE 快照提交，大型集群在状态更新流入时保持流畅。
1. 日志页码替换为上一页 / 下一页游标分页与时间范围选择器（24h / 7d / 30d / 90d / 365d）；消息搜索将范围限制为 30 天。
1. 终端页在缺失 SSH / OS 字段时渲染 Agent 模式服务器，而不是在空地址 / 用户名上抛出错误。
1. 修正监控图表降采样，更长的时间范围（7d / 30d / 180d / 365d）保持合理的点数，而不是坍缩或过度聚合。

## v0.1.12 (13/08/2026)

Github: [aacfbf7...c850eb7](https://github.com/mosona-labs/mosona-manager/compare/aacfbf76041d50cd1324d886441104020fcc15ff...c850eb75fba024359814e815731e5c0eaf02b065)

> 本版本会在启动时重新加密已存储的 SSH 凭据（旧版 AES-CBC → 带版本的 AES-GCM）。应用于自动更新或无人值守实例前，请先阅读升级说明。请勿回滚镜像——v0.1.11 之前的构建无法读取新凭据格式，可能导致崩溃。

#### 安全

1. 端到端凭据加密：使用绑定记录上下文的带版本 AES-GCM 封装，并自动迁移旧版 CBC 密文。
1. 强化主密钥处理：失败即关闭（凭据存在时不再静默重新生成），强制文件权限 / 所有权，拒绝符号链接。
1. SSH 主机密钥固定：新增或编辑的服务器会记录并强制校验主机密钥；现有服务器继续连接（`trust_legacy_host_key`），可在编辑时确认以完成固定。
1. 更强的认证与会话：成员被移除时撤销团队会话；拒绝已撤销的团队访问，而不再静默降级为 viewer；拒绝管理员自删 / 自降级 / 移除最后一名管理员，并要求重新认证。
1. 支持带发现的 OIDC，并校验 OAuth 身份主体（拒绝空 / 0 / 纯空白主体）。
1. 全面资源限制：公开预览流的按 IP / 按团队 / 全局 SSE 限制；请求 / 响应大小限制；上传限制；主动 Agent 服务的 HTTP 超时。
1. 作用域数据访问：服务器分类、告警 upsert 与通知投递现限定到所属团队；分类删除为原子操作。
1. 密钥脱敏：管理设置响应中会脱敏 `smtp_password` 与 `captcha_secret`。

#### 新功能

1. 就绪 / 存活健康检查端点：`/health/ready` 探测 Postgres、Redis 与 InfluxDB。
1. 通知目标预校验：`POST /api/team/notification/validate` 在保存前校验目标。
1. 为 OAuth 提供方增加 OIDC 协议选择。
1. 通用 Webhook 通知，含模板白名单与重定向策略。

#### 修复

1. 审计日志写入改为有界队列并在优雅关闭时排空，不再使用无界 fire-and-forget goroutine。
1. 更清晰的服务器连接生命周期：替换重复的监控连接，编辑 / 删除 / 重装时等待旧连接结束，访问撤销时关闭 Agent 连接。
1. 被动 Agent 的 WebSocket 关闭现为永久关闭，不再在服务端主动关闭后静默重连。
1. 数据库事务在所有退出路径上均会回滚。
1. 自动续期追赶：长期过期的自动续期服务器会推进到下一个未来周期，而不再每小时只推进一个周期。
1. 统一 Redis 密码配置（`REDIS_PASSWORD` / `REDIS_PASS`）。
1. 在主机密钥固定上线期间保留旧版 SSH 连通性。
1. 在写入路径与既有数据上强制告警配置边界。
1. 统一邮件发送以及 base-host / trust-proxy 处理。

#### Web

1. 保存前校验通知目标（独立校验端点）。
1. 特权变更与受保护用户删除的密码重新认证对话框。
1. 成员编辑器中禁用团队所有者角色 / 移除控件。
1. 添加或编辑服务器时确认 SSH 主机密钥。
1. 优雅处理已撤销的团队会话（重定向而非损坏状态）。
1. OAuth 身份协议配置（OAuth 2.0 / OIDC）。
1. 仪表盘服务器卡片增加编辑与删除操作，通过带触控友好 kebab 触发器的共享上下文菜单暴露。（[web#5](https://github.com/mosona-labs/mosona-manager-web/pull/5)）
1. 头像来源由 gravatar.webp.se 切换为 www.gravatar.com。（[web#2](https://github.com/mosona-labs/mosona-manager-web/pull/2)）
