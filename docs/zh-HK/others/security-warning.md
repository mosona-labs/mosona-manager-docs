# 保安警告

> 如需報告漏洞，請前往 [GitHub Security](https://github.com/mosona-labs/mosona-manager/security)，按說明提交 issue 或私下報告。我們會盡快回應並處理。

本頁旨在說明不安全使用本項目可能帶來的風險。請時刻遵循保安最佳做法，保護你的系統與資料。

## 為甚麼這件事很重要

本項目包含遠端控制與執行能力（在啟用遠端控制時）。在 SSH 模式下，它會將連線資料——例如主機位址、用戶名稱、密碼與金鑰——儲存在資料庫中。儘管這些資料已加密，但若攻擊者取得更高權限（例如從資料庫擷取資料，或逃逸出容器），仍可能取回加密金鑰並解密資料。

任何入侵或攻擊都可能造成嚴重後果。遠端探測類能力本身就帶有這類保安風險，沒有任何項目能完全消除——即使本機 SSH 用戶端亦可能被惡意軟件竊取憑證。因此，遵循保安最佳做法至關重要。

歷史上無數項目都因保安疏忽付出過沉重代價。便利與速度往往以額外風險為代價，我們會盡可能減低暴露面。

## 保安最佳做法

### 1. 避免弱密碼

設定符合控制面板密碼強度要求的強密碼。

### 2. 啟用雙重認證（2FA）

請時刻啟用建基於 TOTP 的雙重認證，或電郵驗證。即使密碼外洩，攻擊者亦難以輕易登入。

### 3. 強制存取隔離

初始設定時必須繫結基礎 URL（Base URL）。之後控制面板只可透過該 URL 存取。建議繫結至專用域名，而不是使用 IP 位址。

對於公開頁（Public Pages），最佳做法是使用獨立的專用域名，而不是透過主控制面板路徑共用存取。本項目會阻止來自公開頁域名的所有管理 API 存取。

### 4. 使用 Cloudflare Tunnel 或 VPN

若需要從互聯網存取控制面板，請使用 Cloudflare Tunnel 或 VPN，避免直接暴露伺服器。攻擊者一旦發現實例相關 IP，可能嘗試直接攻擊；隱藏 IP 能顯著減低這項風險。

### 5. 以 Cloudflare Access 或 Zero Trust 保護控制面板

Cloudflare Access 或 Zero Trust 可提供額外的強認證與存取控制，確保只有授權用戶或機構內部用戶能存取控制面板。這是最有效的保安措施之一。

### 6. 保持自動更新開啟

不要關閉自動更新。執行最新版本可確保時刻取得最新的保安修復與改進。
