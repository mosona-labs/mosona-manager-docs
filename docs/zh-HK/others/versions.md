# 版本記錄

## v0.1.16 (04/09/2026)

Github: [3ef7752...5b9fcc1](https://github.com/mosona-labs/mosona-manager/compare/3ef7752d57e1a30d33343784ebaa2d74deff18d2...5b9fcc1f7f5df04be20a26205d36aef5e84138a1)

#### 修正

1. 修正伺服器警報通知從未觸發的問題：批次 InfluxDB 警報查詢將單一時長分組包裹在 `union(tables: [branch0])` 中，被 Flux 拒絕（`union must have at least two streams as input`），因此當團隊對某一項目的規則共用同一回看時長（預設配置）時，每個警報評估週期都會跳過所有規則。單一分組查詢現在直接輸出分支管線。
1. 在 SSH 狀態收集時 `df` 部分失敗（例如失效的 FUSE 掛載使 `df` 列出所有檔案系統後以非零結束）的情況下保留有效磁碟行：磁碟取樣現在使用成功解析的行，而不是捨棄整個快照，僅在 `df` 逾時或完全沒有有效行時才回退至上次快取的取樣。

#### Web

1. 一些細微的設計調整。

## v0.1.15 (30/08/2026)

Github: [3983bdf...3ef7752](https://github.com/mosona-labs/mosona-manager/compare/3983bdf8eea34558239752c4d6c81b472a4671f6...3ef7752d57e1a30d33343784ebaa2d74deff18d2)

> 本版本為主動式 Agent 終端握手加入認證（協定 v2：回覆使用 Agent 的 Ed25519 身分金鑰簽署並由 Hub 固定，中間人無法再冒充 Agent 終端），並強化被動式終端工作階段（綁定其伺服器、原子認領、工作階段 ID 移出 URL）。無降級路徑——套用至自動更新或無人值守實例前請先閱讀升級說明，並請在 v0.1.17 之前升級主動式與被動式 Agent（舊握手屆時將被移除）。

#### 保安

1. 使用綁定到伺服器記錄的帶版本 AES-GCM 封裝，對主動式 Agent 長期私鑰進行靜態加密；執行時連線與匯出拒絕明文或從其他伺服器複製的密文。
1. 對非空 Agent UID 強制唯一性，確保已認證的被動式 Agent 身分唯一解析到一個伺服器；升級遇重複時失敗即關閉，團隊匯入預檢衝突時傳回針對具體伺服器的 409，而非模糊的資料庫錯誤。
1. 團隊匯出遇到無法讀取的憑據時指明受影響的伺服器或共享 SSH 金鑰：預設跳過無法讀取的伺服器及依賴被跳過金鑰的伺服器，並記錄在回應與加密包中；`skip_unreadable_servers: false` 要求嚴格的全有或全無匯出。
1. 將被動式終端工作階段綁定到目標伺服器、首次認領時原子消耗、使用隨機 UUID v4 識別碼、要求已安裝且啟用終端的 Agent，防止跨團隊或重複認領；新端點將工作階段識別碼移出 URL，降低反向代理與 WAF 日誌暴露。
1. 對主動式 Agent 握手回覆的完整紀錄進行簽署與驗證，以原子 compare-and-set 固定身分金鑰，將工作階段金鑰綁定到紀錄，以雙向驗證的 finished 訊息確認，套用 15 秒期限，任何驗證錯誤均失敗即關閉，並在固定到 v2 後拒絕降級至舊握手。
1. 團隊匯入時驗證 Agent `public_key`（PEM 格式與 Ed25519 金鑰長度），儲存前規範化並重新編碼。

#### 新功能

1. 可選的每伺服器 `public_visible` 旗標（預設可見），僅將伺服器從公開狀態頁隱藏——團隊儀表板、監控與終端不受影響。可在新增／編輯時設定；團隊匯出／匯入包含該欄位，不含該欄位的舊包匯入時視為可見。
1. 團隊匯出／匯入包中的 `protocol_version` 欄位，與舊封存向下相容：升級過渡期內未固定的主動式 Agent 保留明確的舊版本，已固定的身分以 v2 匯入。
1. 新增 `docs/testing.md`，說明執行測試套件所需的環境變數。

#### 修正

1. 被動式 Agent 註冊或主動式伺服器建立時使用隨機 UUID v4 身分，產生失敗時失敗即關閉，避免可預測或全零的 Agent 身分。
1. 認證連線上的狀態快照或編碼失敗時，Agent 程序不再透過 `log.Fatalln` 結束，而是關閉連線；框架解密失敗時重新連線監控，而不是讓串流靜默失步。
1. 從連線池移除已完成的 worker，避免已停止或不符的伺服器留下過期條目；Agent 記錄缺失時停止重試循環而不是每分鐘記錄一次錯誤（含 SSH 伺服器），重新執行安裝器時重用現有 Agent 身分。

## v0.1.14 (22/08/2026)

Github: [fc4e444...3983bdf](https://github.com/mosona-labs/mosona-manager/compare/fc4e44489da080103679c70040c61429975a21c3...3983bdf8eea34558239752c4d6c81b472a4671f6)

> 本版本降低了較大規模機群下即時監控與警報對 Hub 的負載，並將日誌 API 改為基於游標的時間範圍查詢。`GET /api/v1/logs` 與 `GET /api/admin/logs` 不再支援偏移分頁（`page` > 1 傳回 400，回應傳回 `next_cursor` / `has_more` 而非 `total`），日誌查詢預設最近 30 天（訊息搜尋限制在 30 天範圍內；最大跨度 365 天）。

#### 新功能

1. 團隊與管理員日誌列表端點支援可選的 RFC3339 `start` / `end` 過濾，並採用基於游標的分頁（`cursor`、`next_cursor`、`has_more`）。

#### 效能

1. 每個團隊的所有 SSE 訂閱者共享同一份監控快照（3 秒重新整理、8 秒查詢逾時、64 個並行 Influx 載入），而不是每個開啟的儀表板各查詢一次 InfluxDB。
1. 將伺服器狀態寫入 InfluxDB 的操作排隊並批次執行（1 萬點佇列、500 點批次、1 秒重新整理），失敗批次重試一次，溢出時捨棄最舊的點，並在關閉時與稽核日誌一起排空佇列。
1. 批次執行警報觀測查詢（每次 64 台伺服器，按指標與 `for_duration` 分組）並預先聚合視窗，取代每伺服器／每規則一次 Influx 查詢。
1. 並行化管理員儀表板的 Influx 查詢（記錄數與系統使用率），附 15 秒上下文逾時。

#### 修正

1. 在 `SafeJoinUnderRoot` 中拒絕父路徑段（`..`），包括反斜線分隔的路徑，靜態檔案拼接無法再透過此前會被清理回根目錄內的穿越段逃逸。
1. 驗證管理員列表分頁（`page` / `size`）的共享邊界（預設 1/20，最大 100000/1000），無效值傳回 400 而不是強制轉換。
1. 在管理員用戶／團隊搜尋中轉義 `LIKE` 萬用字元，數字 ID 精確比對，列出團隊不再要求成員聯結，空團隊也會出現在管理員列表中。

#### Web

1. 儀表板伺服器卡片虛擬化並節流 SSE 快照提交，大型機群在狀態更新流入時保持流暢。
1. 日誌頁碼替換為上一頁／下一頁游標分頁與時間範圍選擇器（24h / 7d / 30d / 90d / 365d）；訊息搜尋將範圍限制為 30 天。
1. 終端頁在缺失 SSH / OS 欄位時渲染 Agent 模式伺服器，而不是在空位址／用戶名稱上拋出錯誤。
1. 修正監控圖表降取樣，更長的時間範圍（7d / 30d / 180d / 365d）保持合理的點數，而不是坍縮或過度聚合。

## v0.1.12 (13/08/2026)

Github: [aacfbf7...c850eb7](https://github.com/mosona-labs/mosona-manager/compare/aacfbf76041d50cd1324d886441104020fcc15ff...c850eb75fba024359814e815731e5c0eaf02b065)

> 本版本會在啟動時重新加密已儲存的 SSH 憑據（舊版 AES-CBC → 帶版本的 AES-GCM）。套用至自動更新或無人值守實例前，請先閱讀升級說明。請勿回滾映像——v0.1.11 之前的建置無法讀取新憑據格式，可能導致崩潰。

#### 保安

1. 端到端憑據加密：使用綁定記錄上下文的帶版本 AES-GCM 封裝，並自動遷移舊版 CBC 密文。
1. 強化主密鑰處理：失敗即關閉（憑據存在時不再靜默重新產生），強制檔案權限／擁有權，拒絕符號連結。
1. SSH 主機金鑰固定：新增或編輯的伺服器會記錄並強制校驗主機金鑰；現有伺服器繼續連線（`trust_legacy_host_key`），可在編輯時確認以完成固定。
1. 更強的認證與工作階段：成員被移除時撤銷團隊工作階段；拒絕已撤銷的團隊存取，而不再靜默降級為 viewer；拒絕管理員自刪／自降級／移除最後一名管理員，並要求重新認證。
1. 支援帶探索的 OIDC，並校驗 OAuth 身份主體（拒絕空／0／純空白主體）。
1. 全面資源限制：公開預覽串流的按 IP／按團隊／全域 SSE 限制；請求／回應大小限制；上傳限制；主動 Agent 服務的 HTTP 逾時。
1. 作用域資料存取：伺服器分類、警報 upsert 與通知投遞現限定到所屬團隊；分類刪除為原子操作。
1. 密鑰脫敏：管理設定回應中會脫敏 `smtp_password` 與 `captcha_secret`。

#### 新功能

1. 就緒／存活健康檢查端點：`/health/ready` 探測 Postgres、Redis 與 InfluxDB。
1. 通知目標預校驗：`POST /api/team/notification/validate` 在儲存前校驗目標。
1. 為 OAuth 提供方增加 OIDC 協定選擇。
1. 通用 Webhook 通知，含範本白名單與重新導向策略。

#### 修正

1. 稽核日誌寫入改為有界佇列並在優雅關閉時排空，不再使用無界 fire-and-forget goroutine。
1. 更清晰的伺服器連線生命週期：取代重複的監控連線，編輯／刪除／重裝時等待舊連線結束，存取撤銷時關閉 Agent 連線。
1. 被動 Agent 的 WebSocket 關閉現為永久關閉，不再在服務端主動關閉後靜默重連。
1. 資料庫事務在所有退出路徑上均會回滾。
1. 自動續期追趕：長期過期的自動續期伺服器會推進到下一個未來週期，而不再每小時只推進一個週期。
1. 統一 Redis 密碼設定（`REDIS_PASSWORD` / `REDIS_PASS`）。
1. 在主機金鑰固定上線期間保留舊版 SSH 連通性。
1. 在寫入路徑與既有資料上強制警報設定邊界。
1. 統一郵件發送以及 base-host / trust-proxy 處理。

#### Web

1. 儲存前校驗通知目標（獨立校驗端點）。
1. 特權變更與受保護用戶刪除的密碼重新認證對話框。
1. 成員編輯器中停用團隊擁有者角色／移除控制項。
1. 新增或編輯伺服器時確認 SSH 主機金鑰。
1. 優雅處理已撤銷的團隊工作階段（重新導向而非損壞狀態）。
1. OAuth 身份協定設定（OAuth 2.0 / OIDC）。
1. 儀表板伺服器卡片增加編輯與刪除操作，透過帶觸控友善 kebab 觸發器的共用內容選單公開。（[web#5](https://github.com/mosona-labs/mosona-manager-web/pull/5)）
1. 頭像來源由 gravatar.webp.se 切換為 www.gravatar.com。（[web#2](https://github.com/mosona-labs/mosona-manager-web/pull/2)）
